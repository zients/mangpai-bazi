Generate: 木 → 火 → 土 → 金 → 水 → 木.
Control: 木 → 土 → 水 → 火 → 金 → 木.

The arrow is directional. 木生火 describes both 火受生 and 木泄出. A control relation alone does not establish successful control, damage, or 反剋. Counting symbols alone cannot establish reversed dominance. Element-level 陰陽 imagery does not change an individual stem's polarity.

## 十神

Classify every participating stem against the original 日干. Keep this reference fixed for original and temporal participants.

| 與日主的關係 | 同陰陽 | 異陰陽 |
| --- | --- | --- |
| 同五行 | 比肩 | 劫財 |
| 生我 | 偏印 | 正印 |
| 我生 | 食神 | 傷官 |
| 我剋 | 偏財 | 正財 |
| 剋我 | 七殺 | 正官 |

For 甲日主: 甲比肩、乙劫財、丙食神、丁傷官、戊偏財、己正財、庚七殺、辛正官、壬偏印、癸正印. Hidden stems receive the same classification but retain their hidden positions. The day stem itself is 日主; it also belongs to the 比肩 category in a mechanical lookup.

Position, roots, strength, 制化, and 假官當財 do not change 十神 identity. A branch can contain several 十神; a 本氣十神 field does not summarize all of them.
