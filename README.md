# mangpai-bazi

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

盲派八字排盤引擎。只負責算，不負責排版，不論吉凶。

給 agent 一行緊湊 JSON；人要讀時自行 `| jq .`。零外部相依。

同倉的 `.agents/skills/` 已收錄盲派理法分析流程，`.claude/skills` 共用同一份。排盤先產生資料，再由 agent 按規則尋根、分賓主、查作用與做功，最後取象。

完整入口：[mangpai-analysis](.agents/skills/mangpai-analysis/SKILL.md)。

**僅供娛樂使用。** 不是專業命理諮詢，不構成任何決策依據。

## 為什麼另做一個

多數排盤工具為人眼排表。agent 讀表格會猜、會漏、會自己重算節氣。時區一旦默補 `+08:00`，年月柱錯了也不報錯——錯盤與對盤長得一樣。

本工具反過來：時刻必須自帶時分與時區偏移，漏給即拒絕。輸出是機器可解析的 JSON，流年逐年寫完，不必再 join。

## 安裝

```sh
cargo install --path .
```

或直接：

```sh
cargo run -- 1990-05-15T14:30+08:00 --gender male
```

## 用法

```sh
bazi 1990-05-15T14:30+08:00 --gender male
bazi 1990-05-15T14:30:00+08:00 -g f --luck 12
bazi 1990-05-15T14:30+08:00 -g m | jq .
```

| 選項 | 說明 |
| --- | --- |
| `-g, --gender` | 必填。`male`/`m`/`男`/`乾`，`female`/`f`/`女`/`坤` |
| `--luck <n>` | 大運步數，預設 10，上限 12 |
| `--early-zi` | 23 時仍算當日，不進次日子時 |
| `-h, --help` | 說明 |

## 時刻

須為出生地之**當地民用時**，且必須寫在 RFC 3339 裡：

```
1990-05-15T14:30:00+08:00
1990-05-15T14:30+08:00        秒可省
1990-05-15 14:30+08:00        空白可代 T
1990-05-15T06:30:00Z          Z 即 +00:00
```

台灣、大陸寫 `+08:00`。他處寫該地**當時**的法定偏移，不管夏令、歷史時區——本工具不查 IANA。

偏移只用來還原世界時，與節氣比對，定年柱、月柱。日柱、時柱用你寫下的鐘點，**不先轉成北京時間再排**。同一瞬間改寫時區：年月不變，日時跟著當地鐘變。

## 輸出

一行 JSON，字串外無空白。頂層六個物件：

| 欄 | 內容 |
| --- | --- |
| `input` | 時刻、性別、時區、晚子時 |
| `pillars` | 四柱。每柱含干支、五行、陰陽、十神、納音、藏干 |
| `day_master` | 日干 |
| `term` | 所在節、下一節、入節日數、太陽視黃經 |
| `luck` | 順逆、起運、交運、`da_yun[]`、`xiao_yun[]` |
| `years` | 生年立春至末運末年，逐年一筆，已嵌當年所行 |

`years[].fortune` 是完整行運，不必再對 `da_yun[]` 做 join。交運落在該干支年之內者，另有 `hand_over`：交運時刻、及其後所行。

大運有兩個不可混的歲：

- `handover_age`：交運當下的虛歲（慣例梯，逐步加十）
- `age_from` / `age_to`：該步所轄虛歲，與 `year_from` / `year_to` 對齊

交運發生在 `handover_age` 那一年中，所轄自次一歲起，故常見 `8` 配 `9`。

`solar_longitude` 是太陽視黃經，與出生地經度無關。

## 本工具的選擇

各家不一之處，此處取：

- 年柱立春換年，月柱以十二節為界，皆非農曆
- 晚子時：23 時進次日。`--early-zi` 可關
- 大運：陽年男、陰年女順行；陰年男、陽年女逆行。起運三日折一年
- 大運本身整整十年。投影到立春格子後，年區間可為九年、十年或十一年——立春游移，交運時刻固定，二線交錯，不是誤差
- 小運與大運同向。`luck.xiao_yun` 只列到起運之歲。取用：有大運取大運，否則取小運
- 流年同立春換年。西元年與干支年不重合
- 年份 1600–2200。1645 年定氣之前的官方曆用平氣，對不上
- 無真太陽時

## 精度

太陽視黃經採 VSOP87D 截斷級數，加 FK5、章動與光行差。2024 年十二節與權威萬年曆差在 20 秒內。生時若落在節氣交界約一分鐘內，宜另核萬年曆。
